# Dynamic Glyph website

The product site for the Dynamic Glyph iPhone app: landing page, `/support/`
and `/privacy/`. The last two are the URLs App Store Connect points at.

Static HTML, no build step, no external requests. Deployed with Cloudflare
Pages: build command empty, build output directory `/`.

## Languages

English pages at the root are the source. Japanese, Simplified Chinese and
Traditional Chinese live in `ja/`, `zh-hans/` and `zh-hant/`, generated by
`python3 tools/build-i18n.py` from `tools/translations.json` (line numbers as
in `tools/strings-en.md`). After changing English text, update the numbered
source and translations, rerun the script and commit its output. There is
still no build step on Cloudflare.
